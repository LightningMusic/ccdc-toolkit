# Strings that Invoke-IISHardening.ps1 looks for inside executable files under a
# web root. A match does NOT mean a file is malicious -- most of these are things
# real applications legitimately do. It means "a human should read this file".
#
# One indicator per line. Blank lines and lines starting with # are ignored.
# Matching is case-insensitive and plain-text (not regex), so nothing here needs
# escaping.
#
# Why this is a data file and not a list inside the script: antivirus (Windows
# Defender's AMSI scan of PowerShell) reacts to attack-shaped strings appearing
# in script SOURCE, and this repo has already had a defensive script blocked as
# "malicious content" for exactly that reason. See docs/SECURITY.md.
#
# Add your own as you learn what your environment actually looks like; remove
# any that match a legitimate application of yours and just create noise.
